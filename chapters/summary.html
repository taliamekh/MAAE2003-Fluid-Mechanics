Which Tool Do I Use?

Fluid Property Selection

Need mass per unit volume? → Density: \(\rho = m/V\)
Need weight per unit volume? → Specific weight: \(\gamma = \rho g\)
Comparing to water (dimensionless)? → Specific gravity: \(SG = \rho / \rho_W\)
SG > 1? → sinks  |  SG < 1? → floats
Shear stress from velocity profile? → Newton: \(\tau = \mu \, du/dy\) (Newtonian only)
Reynolds number / diffusivity? → Kinematic viscosity: \(\nu = \mu/\rho\)
Pressure inside a droplet/bubble? → \(\Delta p = 2\Upsilon/R\) (droplet) or \(4\Upsilon/R\) (bubble)
Gas density at given p and T? → Ideal gas law: \(\rho = p/(RT)\)

Pressure & Manometry

Need pressure at a depth? → \(p = p_a + \gamma h\) (static, incompressible)
Converting gage ↔ absolute? → \(p_{\text{abs}} = p_{\text{gage}} + p_{\text{atm}}\)
Pressure difference via manometer? → Walk through: +γΔh down, −γΔh up
Multiple stacked fluids? → Sum γihi for each layer

Hydrostatic Forces on Surfaces

Total force on a flat submerged surface? → \(F_R = \gamma \bar{h} A\)
Where does the force act? → Center of pressure: \(y_{cp} = \bar{y} + I_{xx}/(\bar{y}A)\)
Curved surface? → Project onto horizontal & vertical planes, combine components
Equilibrium (hinge/stop/bolt forces)? → Draw FBD, sum moments about hinge using F_R at y_cp

Ch 1 — Fluid Properties & Pressure

Ch 1 — Fluid Properties & Pressure

Key ideas:

  • → A fluid deforms continuously under shear stress — it never reaches static equilibrium under shear
  • → The continuum assumption lets us treat ρ, p, V as smooth functions, enabling calculus-based equations
  • → Every valid equation must be dimensionally homogeneous — every term has the same primary dimensions
  • → Viscosity measures resistance to shear deformation; surface tension measures resistance to surface stretching
  • → Pressure in a static fluid increases linearly with depth: p = pa + γh
  • → Manometers measure pressure differences by walking through connected fluid columns

When to use what:

  • → Need density? — \(\rho = m/V\); for gases: \(\rho = p/(RT)\)
  • → Need weight per volume? — \(\gamma = \rho g\)
  • → Sinks or floats? — \(SG = \rho/\rho_W\); >1 sinks, <1 floats
  • → Shear stress? — \(\tau = \mu \, du/dy\) (linear profile ⇒ constant gradient)
  • → Reynolds number? — \(\nu = \mu/\rho\)
  • → Droplet pressure? — \(\Delta p = 2\Upsilon/R\); bubble: \(4\Upsilon/R\)
  • → Capillary rise? — \(h = 2\Upsilon\cos\theta / (\gamma R)\)
  • → Pressure at depth? — \(p = p_a + \gamma h\)
  • → Convert gage ↔ absolute? — \(p_{\text{abs}} = p_{\text{gage}} + p_{\text{atm}}\)
  • → Pressure difference via manometer? — Walk: +γΔh down, −γΔh up

⚠ Traps:

  1. “Cannot resist shear” ≠ “has no viscosity.” Fluids resist the rate of deformation — they just never stop deforming
  2. Never mix SI and BG units in the same equation
  3. Liquid viscosity decreases with T; gas viscosity increases — opposite trends
  4. Don’t confuse ρ with γ (differ by g), or μ with ν (differ by ρ)
  5. Bubble pressure is 2× droplet (two surfaces). Capillary h is negative for non-wetting (θ > 90°)
  6. Ideal gas law needs absolute p and T — never gauge or °C
  7. Manometer sign convention: going DOWN in a fluid ADDS γΔh. Easy to reverse
  8. pgage can be negative (vacuum). pabs is never negative

Ch 2 — Hydrostatic Forces & Buoyancy

Ch 2 — Hydrostatic Forces & Buoyancy

Key ideas:

  • → Hydrostatic pressure on a submerged surface varies linearly with depth — the resultant force equals the pressure at the centroid times the area
  • → The center of pressure is always below the centroid — the offset depends on the shape’s second moment of area
  • → For curved surfaces, decompose into horizontal and vertical components using projected areas

When to use what:

  • → Total force on a flat surface? — \(F_R = \gamma \bar{h} A\)
  • → Where does FR act? — \(y_{cp} = \bar{y} + I_{xx}/(\bar{y}A)\)
  • → Lateral offset? — \(x_{cp} = \bar{x} + I_{xy}/(\bar{y}A)\) (for asymmetric shapes)
  • → Moment about a hinge? — Draw FBD, use FR at ycp, sum moments
  • → Gage pressure simplification? — Set pa = 0, then \(\bar{h}\) is depth below liquid surface

⚠ Traps:

  1. \(\bar{y}\) is measured along the inclined surface from the free-surface line, not vertically — vertical depth is \(\bar{h}\) = \(\bar{y}\) sinθ
  2. Ixx must be about the centroidal axis of the shape — don’t use the parallel axis value
  3. Center of pressure approaches centroid as depth increases (offset ∝ 1/\(\bar{y}\)) — deep surfaces have negligible offset
