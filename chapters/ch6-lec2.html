6.2 — Pipe Flow Losses II

Text §6.6 · The three single-pipe problems — Type 1 (find the loss), Type 2 (find the flow), Type 3 (size the pipe) — and how to solve each with the Moody chart, an explicit formula, or iteration.

Three Questions, One Equation

In §6.1 we built the whole machine for pipe friction: classify the flow with the Reynolds number \(\mathrm{Re}_d\), get the Darcy friction factor \(f\) (exact \(64/\mathrm{Re}_d\) if laminar, the Moody chart or Colebrook if turbulent), and feed it into the Darcy–Weisbach equation \(h_f = f\frac{L}{d}\frac{V^2}{2g}\). Every worked example there handed us the pipe (\(d\)) and the flow (\(Q\) or \(V\)) and asked for the loss \(h_f\). But real analysis and design ask the reverse questions too.

For a single pipe of fixed length, exactly three quantities matter: the diameter \(d\), the volume flow rate \(Q\), and the friction head loss \(h_f\). Give any two and you can find the third — which gives three problem types, named by which quantity is unknown.

The Three Single-Pipe Problems
  • Type 1 — given \(d\) and \(Q\), find \(h_f\). A rating problem: the pipe and the flow are fixed, and we ask how much head friction eats.
  • Type 2 — given \(d\) and \(h_f\), find \(Q\). An analysis problem: the pipe and the head available are fixed, and we ask what flow it can carry.
  • Type 3 — given \(Q\) and \(h_f\), find \(d\). A design problem: the required flow and the allowable head loss are fixed, and we ask how big a pipe to install.

All three are tied together by the same Darcy–Weisbach equation (#48). What changes is which variable we solve it for — and that turns out to matter a great deal.

Fig 6.2.1 — The three single-pipe problems, set by which of \(\{d,\,Q,\,h_f\}\) is unknown. Type 1 marches straight through; Types 2 and 3 hide the velocity and need a special trick or iteration.
★ Key Insight — Why Types 2 and 3 Are Harder

In Type 1 you can march straight through: \(V \to \mathrm{Re}_d \to f \to h_f\). Every input on the way is known. In Types 2 and 3 the velocity is unknown, so \(\mathrm{Re}_d\) is unknown, so the friction factor \(f\) — which depends on \(\mathrm{Re}_d\) — cannot be read until you already have the answer. That circular dependence is the whole story of this lecture: it forces an explicit closed-form trick (Type 2) or iteration (Type 3).

Type 1 — Rating (find \(h_f\))

Type 1 is exactly the workflow from §6.1, so we only review it here on one clean example. Because \(d\) and \(Q\) are both known, the velocity comes straight from continuity and nothing is circular — you compute each quantity once, in order.

Type 1 — The Direct March
\[ V=\frac{Q}{A}=\frac{4Q}{\pi d^2}\;\longrightarrow\; \mathrm{Re}_d=\frac{Vd}{\nu}\;\longrightarrow\; \text{regime}\;\longrightarrow\; f \;\longrightarrow\; h_f=f\,\frac{L}{d}\,\frac{V^2}{2g} \]

Get \(f\) from \(f=64/\mathrm{Re}_d\) (#50) if laminar, or from the Moody chart / Colebrook–Haaland (#51) with the relative roughness \(\varepsilon/d\) if turbulent. Nothing here is guessed — this is the easy direction.

Fig 6.2.2 — The Moody chart (same chart as §6.1). It is the workhorse for Type 1 (read \(f\) directly) and Type 3 (read a new \(f\) each iteration). Enter at \(\mathrm{Re}_d\) on the bottom, follow up to the \(\varepsilon/d\) curve, read \(f\) on the left.
⚑
Where do the \(\varepsilon\) values come from?
Wall roughness \(\varepsilon\) for commercial pipes is a table look-up — the full 16-row table is in §6.1. The values used in this lecture: cast iron \(\varepsilon = 0.26\) mm; the Type 2 and Type 3 examples give \(\varepsilon = 0.06\) mm directly.
Example 1 (Type 1): Head loss in a cast-iron oil line

Problem. Oil with \(\rho = 900\ \text{kg/m}^3\) and \(\nu = 1\times10^{-5}\ \text{m}^2/\text{s}\) flows at \(Q = 0.2\ \text{m}^3/\text{s}\) through \(L = 500\ \text{m}\) of \(d = 200\)-mm-diameter cast-iron pipe. Determine the friction head loss \(h_f\).

Given: \(\rho = 900\ \text{kg/m}^3\);  \(\nu = 1\times10^{-5}\ \text{m}^2/\text{s}\);  \(Q = 0.2\ \text{m}^3/\text{s}\);  \(L = 500\ \text{m}\);  \(d = 0.2\ \text{m}\) (so \(R = 0.1\ \text{m}\)); cast iron.

Step 1 — Average velocity from \(V = Q/A\) with \(A = \pi R^2\):

\[ V = \frac{Q}{\pi R^2} = \frac{0.2\ \text{m}^3/\text{s}}{\pi(0.1\ \text{m})^2} = 6.37 \approx 6.4\ \text{m/s} \]

Step 2 — Reynolds number (use \(V \approx 6.4\) m/s):

\[ \mathrm{Re}_d = \frac{Vd}{\nu} = \frac{(6.4\ \text{m/s})(0.2\ \text{m})}{1\times10^{-5}\ \text{m}^2/\text{s}} = 128{,}000 \quad\Rightarrow\quad \textbf{turbulent} \]

Step 3 — Relative roughness. From the roughness table, cast iron has \(\varepsilon = 0.26\) mm:

\[ \frac{\varepsilon}{d} = \frac{0.26\ \text{mm}}{200\ \text{mm}} = 0.0013 \]

Step 4 — Friction factor from the Moody chart (Fig 6.2.2). Enter at \(\mathrm{Re}_d = 128{,}000\), follow up to the \(\varepsilon/d = 0.0013\) curve:

\[ \left.\begin{array}{l}\mathrm{Re}_d = 128{,}000\\[2pt] \varepsilon/d = 0.0013\end{array}\right\} \;\Rightarrow\; f \approx 0.0225 \]

Step 5 — Head loss from Darcy–Weisbach (#48):

\[ h_f = f\,\frac{L}{d}\,\frac{V^2}{2g} = (0.0225)\frac{500\ \text{m}}{0.2\ \text{m}}\,\frac{(6.4\ \text{m/s})^2}{2(9.81\ \text{m/s}^2)} \]

Therefore \(h_f \approx 117\ \text{m}\) of oil. Over 500 m of pipe at 6.4 m/s, friction alone costs 117 m of head.

Type 2 — Analysis (find \(Q\))

Now the unknown is the flow \(Q\), and therefore the velocity \(V\), and therefore \(\mathrm{Re}_d\), and therefore \(f\). We could guess \(f\) and iterate (and that always works), but for turbulent flow there is a slick way to get the answer in one shot: bundle the knowns into a single dimensionless group so that the velocity cancels out completely.

Step 1 — Dimensionless Head Loss \(\zeta\)
\[ \zeta = \frac{g\,d^3\,h_f}{L\,\nu^2} \]
\(\zeta\) — dimensionless head-loss group (dimensionless) \(g\) — gravitational acceleration (9.81 m/s²) \(d\) — pipe diameter (m) \(h_f\) — friction head loss (m) \(L\) — pipe length (m) \(\nu\) — kinematic viscosity (m²/s)

Every quantity inside \(\zeta\) is known in a Type 2 problem — there is no velocity in it. It comes from substituting \(V = \nu\,\mathrm{Re}_d/d\) into Darcy–Weisbach, which gives the tidy identity \(\zeta = \tfrac12 f\,\mathrm{Re}_d^2\). That single combination is exactly what we need to invert the Colebrook formula.

Step 2 — Reynolds Number, Explicitly
\[ \mathrm{Re}_d = -\,(8\zeta)^{1/2}\,\log\!\left(\frac{\varepsilon/d}{3.7} + \frac{1.775}{\sqrt{\zeta}}\right) \]
\(\mathrm{Re}_d\) — Reynolds number (dimensionless) \(\zeta\) — dimensionless head-loss group from Step 1 \(\varepsilon/d\) — relative roughness (dimensionless) \(\log\) — base-10 logarithm

This is the Colebrook turbulent-friction law (#51) inverted using \(\zeta = \tfrac12 f\,\mathrm{Re}_d^2\). It hands you \(\mathrm{Re}_d\) directly from the knowns — no chart, no iteration. It is valid for turbulent flow, so always sanity-check that the answer is \(> 4000\).

Step 3 — Velocity, then Flow Rate
\[ V = \frac{\nu\,\mathrm{Re}_d}{d} \qquad\text{and}\qquad Q = V\,\frac{\pi}{4}\,d^2 \]

The first is just the Reynolds-number definition (#47) solved for \(V\); the second is continuity \(Q = V\!A\) (#18) with \(A = \tfrac{\pi}{4}d^2\). Two arithmetic steps and you are done.

★ Alternative — Iterate on \(f\)

If you would rather not use the explicit formula, guess a friction factor (\(f \approx 0.02\) is a good start), solve Darcy–Weisbach for the velocity, \(V = \sqrt{2g\,d\,h_f/(fL)}\), compute \(\mathrm{Re}_d = Vd/\nu\), read a new \(f\) from the Moody chart, and repeat until \(f\) stops changing. It converges in a couple of passes and lands on the same answer as the \(\zeta\) formula.

Example 2 (Type 2): Flow rate in a 30-cm oil pipe

Problem. Oil with \(\rho = 950\ \text{kg/m}^3\) and \(\nu = 2\times10^{-5}\ \text{m}^2/\text{s}\) flows through a \(d = 30\)-cm-diameter pipe \(L = 100\) m long with roughness \(\varepsilon = 0.06\) mm and a head loss of \(h_f = 8\) m. Find the average velocity and the flow rate \(Q\).

Given: \(\rho = 950\ \text{kg/m}^3\);  \(\nu = 2\times10^{-5}\ \text{m}^2/\text{s}\);  \(d = 0.3\ \text{m}\);  \(L = 100\ \text{m}\);  \(\varepsilon = 0.06\ \text{mm} = 6\times10^{-5}\ \text{m}\);  \(h_f = 8\ \text{m}\).

Step 1 — Dimensionless head loss \(\zeta\):

\[ \zeta = \frac{g\,d^3\,h_f}{L\,\nu^2} = \frac{(9.81\ \text{m/s}^2)(0.3\ \text{m})^3(8.0\ \text{m})}{(100\ \text{m})(2\times10^{-5}\ \text{m}^2/\text{s})^2} = 5.30\times10^{7} \]

Step 2 — Relative roughness:

\[ \frac{\varepsilon}{d} = \frac{6\times10^{-5}\ \text{m}}{0.3\ \text{m}} = 0.0002 \]

Step 3 — Reynolds number from the explicit formula:

\[ \mathrm{Re}_d = -\big[8(5.30\times10^{7})\big]^{1/2}\log\!\left(\frac{0.0002}{3.7} + \frac{1.775}{\sqrt{5.30\times10^{7}}}\right) = 72{,}600 \]

Since \(72{,}600 > 4000\), the flow is turbulent, so the explicit (Colebrook-based) formula was the right tool. ✓

Step 4 — Velocity from \(V = \nu\,\mathrm{Re}_d/d\):

\[ V = \frac{\nu\,\mathrm{Re}_d}{d} = \frac{(2\times10^{-5}\ \text{m}^2/\text{s})(72{,}600)}{0.3\ \text{m}} \approx 4.84\ \text{m/s} \]

Step 5 — Flow rate from \(Q = V\frac{\pi}{4}d^2\):

\[ Q = V\,\frac{\pi}{4}\,d^2 = \left(4.84\ \tfrac{\text{m}}{\text{s}}\right)\frac{\pi}{4}(0.3\ \text{m})^2 \]

Therefore \(V \approx 4.84\ \text{m/s}\) and \(Q \approx 0.342\ \text{m}^3/\text{s}\).

Type 3 — Design (find \(d\))

The hardest case: the diameter \(d\) is unknown, and it appears in three places at once — inside \(\mathrm{Re}_d\), inside the relative roughness \(\varepsilon/d\), and inside the loss equation. No single rearrangement isolates it, so Type 3 is always solved by iteration: guess the friction factor, solve for a trial diameter, correct the friction factor, and repeat until it settles.

Diameter from Darcy–Weisbach
\[ f = h_f\,\frac{d}{L}\,\frac{2g}{V^2} = \frac{\pi^2}{8}\,\frac{g\,h_f\,d^5}{L\,Q^2} \qquad\Longrightarrow\qquad d^5 = \frac{8\,f\,L\,Q^2}{\pi^2 g\,h_f} \]
\(d\) — pipe diameter (m) \(f\) — Darcy friction factor (dimensionless) \(L\) — pipe length (m) \(Q\) — volume flow rate (m³/s) \(g\) — gravitational acceleration (9.81 m/s²) \(h_f\) — friction head loss (m)

This is Darcy–Weisbach with \(V = 4Q/(\pi d^2)\) substituted in, then solved for \(d^5\). Given a value of \(f\), it returns a trial diameter directly.

Reynolds Number from the Flow Rate
\[ \mathrm{Re}_d = \frac{4Q}{\pi\,d\,\nu} \]
\(\mathrm{Re}_d\) — Reynolds number (dimensionless) \(Q\) — volume flow rate (m³/s) \(d\) — pipe diameter (m) \(\nu\) — kinematic viscosity (m²/s)

The Reynolds number rewritten with \(V = 4Q/(\pi d^2)\) so it depends on the trial diameter directly — handy because \(Q\) is fixed and \(d\) changes every pass.

Type 3 Iteration Recipe
  1. Guess \(f\) — \(0.02\text{–}0.03\) is a good start.
  2. Solve for \(d\) using \(d^5 = 8fLQ^2/(\pi^2 g h_f)\).
  3. Compute \(\mathrm{Re}_d = 4Q/(\pi d\nu)\) and the relative roughness \(\varepsilon/d\).
  4. Read a new \(f\) from the Moody chart with that \(\mathrm{Re}_d\) and \(\varepsilon/d\).
  5. Repeat from step 2 until \(f\) (and \(d\)) stop changing.

Because \(d\) enters as the fifth root, it is forgiving of a rough first guess: even a fairly wrong \(f\) gives a diameter close to the answer, so the iteration converges in just two or three passes.

Example 3 (Type 3): Size the pipe

Problem. The same oil (\(\rho = 950\ \text{kg/m}^3\), \(\nu = 2\times10^{-5}\ \text{m}^2/\text{s}\)) must carry \(Q = 0.342\ \text{m}^3/\text{s}\) through a \(L = 100\) m pipe of roughness \(\varepsilon = 0.06\) mm, with a head loss of \(h_f = 8\) m. Find the required diameter \(d\). (This is the inverse of Example 2, so we expect \(d \approx 0.30\) m — a good consistency check at the end.)

Given: \(\rho = 950\ \text{kg/m}^3\);  \(\nu = 2\times10^{-5}\ \text{m}^2/\text{s}\);  \(Q = 0.342\ \text{m}^3/\text{s}\);  \(L = 100\ \text{m}\);  \(\varepsilon = 6\times10^{-5}\ \text{m}\);  \(h_f = 8\ \text{m}\).

Iteration 1 — guess \(f = 0.03\). Solve for \(d\):

\[ d^5 = \frac{8\,f\,L\,Q^2}{\pi^2 g\,h_f} = \frac{8(0.03)(100)(0.342)^2}{\pi^2(9.81)(8)} \quad\Rightarrow\quad d = 0.325\ \text{m} \]
\[ \mathrm{Re}_d = \frac{4Q}{\pi d\nu} = \frac{4(0.342)}{\pi(0.325)(2\times10^{-5})} = 67{,}000, \qquad \frac{\varepsilon}{d} = \frac{0.06}{325} = 0.000185 \]

From the Moody chart with \(\mathrm{Re}_d = 67{,}000\) and \(\varepsilon/d = 0.000185\): \(f_{\text{new}} \approx 0.0203\).

Iteration 2 — use \(f = 0.0203\).

\[ d^5 = \frac{8(0.0203)(100)(0.342)^2}{\pi^2(9.81)(8)} \quad\Rightarrow\quad d = 0.301\ \text{m} \]
\[ \mathrm{Re}_d = \frac{4(0.342)}{\pi(0.301)(2\times10^{-5})} = 72{,}500, \qquad \frac{\varepsilon}{d} = \frac{0.06}{301} = 0.0002 \]

From the Moody chart with \(\mathrm{Re}_d = 72{,}500\) and \(\varepsilon/d = 0.0002\): \(f \approx 0.021\).

Iteration 3 — use \(f = 0.021\). Solving once more gives \(d \approx 0.300\) m — essentially unchanged from Iteration 2, so the iteration has converged.

Therefore \(d \approx 0.30\ \text{m}\) (a 30-cm pipe). This is exactly the pipe of Example 2 carrying \(Q = 0.342\ \text{m}^3/\text{s}\) at \(h_f = 8\) m — the Type 2 and Type 3 results are consistent. ✓

Naming the Type Is Half the Battle

Once you can spot which of \(\{d,\,Q,\,h_f\}\) is missing, the whole solution path is decided before you touch a calculator. Type 1 is a single straight pass; Type 2 is one explicit formula (or a short iteration); Type 3 is always an iteration. Everything else — Reynolds number, the Moody chart, Darcy–Weisbach — is shared machinery from §6.1.

★
Exam tip — identify the type first
Before any numbers, check what is missing. Missing \(h_f\) → Type 1, march straight through \(V\!\to\!\mathrm{Re}_d\!\to\!f\!\to\!h_f\). Missing \(Q\) → Type 2, use \(\zeta = gd^3h_f/(L\nu^2)\) then the explicit \(\mathrm{Re}_d\) (or iterate on \(f\)). Missing \(d\) → Type 3, iterate: guess \(f\) → \(d^5 = 8fLQ^2/(\pi^2 g h_f)\) → \(\mathrm{Re}_d = 4Q/(\pi d\nu)\), \(\varepsilon/d\) → Moody → repeat. Naming the type tells you instantly whether you can solve in one pass or must iterate.
⚠
Common trap
Do not try to run the Type 1 recipe directly on a Type 2 or Type 3 problem. With the velocity unknown you cannot get \(\mathrm{Re}_d\), and so you cannot read \(f\) — you must use the explicit \(\zeta\) formula or iterate. Also keep \(\varepsilon\) and \(d\) in the same units when forming \(\varepsilon/d\), and remember the Moody-chart read for \(f\) is only good to a couple of percent, which is why the last digit of an iterated \(d\) is not meaningful.
